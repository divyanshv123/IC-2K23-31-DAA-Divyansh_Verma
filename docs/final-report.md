- **Key Outcome:** Formulated the relationship between asymptotic bounds and empirical execution measurements.

## Unit 02: Divide and Conquer
- **Focus:** Binary Search, Maximum & Minimum, Merge Sort, Quick Sort, Heap Sort, Strassen's Matrix Multiplication, and Sorting Performance Comparison System.
- **Key Outcome:** Mastered recursive decomposition, Master Theorem recurrences, and practical CPU cache effects in sorting.

## Unit 03: Greedy Method
- **Focus:** Fractional Knapsack, Job Sequencing with Deadlines, Prim's Algorithm, Kruskal's Algorithm with Disjoint Sets (DSU), and Minimum-Cost Network Design System.
- **Key Outcome:** Identified the greedy choice property and proved conditions under which locally optimal choices yield global optima.

## Unit 04: Dynamic Programming
- **Focus:** Memoized Fibonacci, 0/1 Knapsack, Multistage Graph Shortest Path, Floyd-Warshall All-Pairs Shortest Path, Bellman-Ford Single-Source Shortest Path, Held-Karp Traveling Salesperson Problem, and Logistics Route Optimization System.
- **Key Outcome:** Formulated multi-stage Bellman equations, tabular bottom-up implementations, and bitmask state compression.

---

## Unit 05: Basic Traversal & Search Techniques
- **Focus:** Binary Tree creation and traversals (recursive & iterative Preorder, Inorder, Postorder), Graph Representations (Adjacency Matrix & List), Breadth First Search (BFS), Depth First Search (DFS), and Network Traversal & Exploration System.
- **Key Outcome:** Designed efficient queue-based and stack-based traversals for topological, routing, and reachability analysis.

---

## Unit 06: Backtracking
- **Focus:** N-Queens problem (4-Queens, 8-Queens, N-Queens), Sum of Subsets with two-sided pruning, Graph $m$-Coloring, 9x9 Sudoku Puzzle Solver, and Constraint Satisfaction Benchmark System.
- **Key Outcome:** Evaluated recursive depth-first state-space tree exploration with bounding functions to prune infeasible solution branches.

---

## Unit 07: NP-Hard, NP-Complete & Advanced Optimization
- **Focus:** Exhaustive (Brute-Force) Search demonstration, 0/1 Knapsack using Least-Cost Branch and Bound, Traveling Salesperson Problem using Branch and Bound with reduced cost matrices, DP vs. B&B comparative benchmarks, and Optimization Algorithm Comparison System.
- **Key Outcome:** Explored intractable problem classes and demonstrated how branch-and-bound bounding functions prune factorial and exponential state spaces.
