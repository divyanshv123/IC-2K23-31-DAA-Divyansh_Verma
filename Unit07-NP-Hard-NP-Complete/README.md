# Unit 07: NP-Hard, NP-Complete & Advanced Optimization (CO5, CO7)

## Overview
This unit investigates **Intractable Problems, NP-Hard / NP-Complete complexity classes**, and advanced optimization techniques. It covers Exhaustive (Brute-Force) Search, Branch and Bound (Least-Cost search with bounding functions), and rigorous comparative benchmarks contrasting Dynamic Programming with Branch and Bound for 0/1 Knapsack and Traveling Salesperson problems.
