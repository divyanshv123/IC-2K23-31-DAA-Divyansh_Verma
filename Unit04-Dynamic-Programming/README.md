# Unit 04: Dynamic Programming (CO3)

## Overview
This unit focuses on the **Dynamic Programming** design paradigm, which solves complex problems by breaking them down into overlapping subproblems, solving each subproblem once, and storing their solutions (memoization or tabulation) to achieve polynomial-time efficiency.
