# Unit 03: Greedy Method (CO2)

## Overview
This unit focuses on the **Greedy Method** design paradigm, which constructs solutions incrementally by always selecting the locally optimal choice at each step with the goal of reaching a global optimum. Key topics include item optimization, job scheduling, and minimum spanning tree (MST) generation.
