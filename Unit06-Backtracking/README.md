# Unit 06: Backtracking (CO4)

## Overview
This unit focuses on the **Backtracking** algorithmic paradigm, which systematically searches for solutions by constructing candidate solutions incrementally and abandoning ("backtracking" from) a candidate as soon as it is determined that it cannot possibly be completed to a valid solution. Topics include classical puzzle solving, combinatorial optimization, and search space analysis.
