# Unit 02: Divide and Conquer (CO1)

## Overview
This unit focuses on the **Divide and Conquer** algorithmic design paradigm, which operates by breaking a problem into smaller sub-problems, solving them recursively, and combining their solutions. It covers searching, finding extreme values, optimal sorting algorithms, matrix multiplication, and empirical performance analysis.
